# ZeusReader `v0.4.0-private` (versionCode 4)

## What's New
- **Ink & Hue ("Liquid Glass") UI:** Frosted translucent surfaces, `HueAuraBackground`, 6 hue presets + Auto from cover, and dedicated `Home` vs `Library` tabs with double-back-to-exit navigation.
- **Virtual Racks & Covers:** Automatic EPUB/PDF cover extraction, Open Library metadata lookup, and category shelves (`Fiction`, `Non-Fiction`, `Self-Help`, `History`, `Autobiography`, `Science`).
- **Enhanced Reading Experience:**
  - Fixed Readium `EpubNavigatorFragment` attachment (`doOnAttach`).
  - PDF OCR / Text Selection overlay (`Save passage`, `Highlight`, `Define`), directional swipe (left-to-right = forward, right-to-left = backward), and direct PDF page search-quad highlights.
  - Live Appearance Preview card in `Reading Appearance & Ergonomics`.
  - Unobscured full-width book title in reader top bars.
- **Passages & Card Studio:** Offline quote capture, folders, FTS4 search, and PNG/JPG share cards.
- **Cloudflare Worker Relay (`zeusreader-relay`):** Serverless Open SLUM status/search, D1 sync/transfers, and Workers AI passage explanations/tag suggestions.
- **In-App GitHub Updater:** Automatic update check against GitHub Releases with release notes and user-confirmed APK download & install.
